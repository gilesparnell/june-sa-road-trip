# G1.3b — Long Tom real audio sourcing (deferred)

G1.3 polish shipped with Kaplay built-in burp() placeholder SFX. This
unit replaces them with curated CC0 audio from Freesound.

## Prereqs

- `brew install ffmpeg` (for .m4a conversion — current dev box lacks it)
- Freesound.org account (free) — needed for download access

## Search terms (per G1 design)

| Id      | Search terms                                | Target length |
|---------|---------------------------------------------|--------------:|
| aim     | "ui pop", "select chirp"                    | 0.05s         |
| fire    | "cannon shot", "artillery fire"             | 0.6s          |
| hit     | "wood explosion", "barrel destroy"          | 0.4s          |
| miss    | "ground impact", "dirt explosion"           | 0.3s          |
| fanfare | "brass triumph", "victory short"            | 1.2s          |

License: CC0 only (filter on Freesound's License facet).

## Conversion

```bash
ffmpeg -i source.wav -c:a aac -b:a 96k -ac 1 -y \
  v2/games/long-tom/assets/audio/<id>.m4a
```

Target: AAC 96kbps mono, ~30-50KB per clip. Total audio asset budget
≤ 200KB per the F6 research.

## Wiring back into game.js

1. Drop the 5 .m4a files at `v2/games/long-tom/assets/audio/`
2. Uncomment the `await loadSounds(k, { ... })` block at top of `startGame`
3. Replace the `sfx(k, "<id>")` placeholder calls with `k.play("<id>")`
4. Remove the placeholder `SFX` constant + `sfx()` helper from game.js
5. Bump SW VERSION + add the .m4a files to PRECACHE_URLS
